# 设计系统 · Design System

> 本文件是 qianjin-poster 的"专业度地基"。所有海报——无论 PIL 直出还是提示词生图——都必须先在本系统设计，再执行。
> 目标：让 AI 产出"设计师水准"的海报，而非"排版器式"的图文堆叠。

---

## 〇、设计哲学：先 Concept，再 Layout

**专业海报与业余排版的本质区别，在于有没有"设计概念（Concept）"。**

概念 = 这张海报想让人**一眼记住的一个视觉念头**。它是一句话，例如：
- 经络理疗仪 → 「足底暖流，看得见」（把"温热"可视化成发光经络线）
- 冰饮 → 「一口降温 20℃」（把温度做成视觉主符号）
- 降噪耳机 → 「世界静音了」（用大片留白+产品悬浮表达"安静"）

**执行顺序（铁律）**：
```
Concept（想清楚要记住什么）
  → Style（选风格，定配色/字体/装饰基调）
    → Layout（选构图，定元素位置与视线）
      → Copy（提炼文案，服务 Concept）
        → Compose（执行合成）
```

没有 Concept 直接排版 = 业余。每次出图前，先用一句话写下 Concept。

## 一、栅格系统（Grid）

所有元素吸附到栅格，禁止自由散落。

### 1.1 列栅格
- **基准画布宽 750px**（竖版/方形按此缩放，横版按高 750 缩放）。
- **8 列栅格**：列宽 = (W - 2×margin) / 8，margin = W×6%。
- 文字块/色块宽度取 2/3/4/6/8 列的整数倍，不取奇数碎片列。

### 1.2 基线（Baseline）
- 行高基准 8px。所有元素 Y 坐标对齐到 8 的倍数。
- 安全边距：内容距画布边缘 ≥6%（约 45px@750宽）。

### 1.3 视觉重心
- 主视觉（产品/人物）置于**画面重心**（非几何中心，略偏上 1/3 或黄金分割点 0.382/0.618）。
- 文字块与产品块**咬合**（相邻或重叠遮挡），不分离成"上下两截"。

---

## 二、字阶 Type Scale（@750宽基准）

单一字体单字重 = 业余。必须建立字阶，形成 Display→Body 的清晰落差。

| 层级 | 字号 | 字重 | 用途 | 字间距 |
|------|------|------|------|--------|
| **Display** | 88–120px | Heavy(900) | 主标题/超级符号 | 0 ~ -2% |
| **H1** | 56–72px | Bold(700) | 副标题/主张 | 0 |
| **H2** | 40–48px | Medium(500) | 区块标题 | 0 |
| **Body** | 26–32px | Regular(400) | 利益点/说明 | 2–4% |
| **Caption** | 18–22px | Regular | 角标/刊号/辅助小字 | 8–12%（字间距拉开） |

**规则**：
- 主→次字号梯度 **≥1.5 倍**，否则是清单不是海报。
- 中文用思源/阿里普惠 Heavy；英文数字用 Montserrat/Barlow **Bold 或 Black** 做价格、年份、型号等"硬信息"。
- 行距：Display 1.05、H1 1.15、Body 1.45。
- 字间距：Caption 与小标必须拉开字间距（letter-spacing 8–12%），这是"高级感"的关键细节。

---

## 三、间距尺度（Spacing）

统一间距，避免随机。尺度基于 8px 倍数：
`4 / 8 / 16 / 24 / 40 / 64 / 96`

- 标题与副标题间距：24–40px
- 副标题与利益点：40px
- 利益点之间：16px
- 文字块与产品块：≥24px 或刻意重叠（前景遮挡）
- 区块之间用 64/96 制造呼吸

---

## 四、语义化配色 Token

禁止"随机选两个颜色渐变"。配色用**语义 Token**，每套风格定义如下：

| Token | 含义 | 约束 |
|-------|------|------|
| `--bg` | 背景主色 | 决定整体调性 |
| `--bg-2` | 背景辅色（渐变终止/色块） | 与 bg 同色系或对比 |
| `--ink` | 主文字色（标题/硬信息） | 与 bg 对比 ≥4.5:1 |
| `--ink-soft` | 次文字色（说明） | 与 bg 对比 ≥3:1 |
| `--accent` | 强调色（点睛/价格/符号） | **全图唯一高饱和色**，只用于 1–2 处 |
| `--surface` | 色块/胶囊底色（承载文字） | 提高文字可读性的衬底 |

**配色铁律**：
- 一图 ≤3 主色 + 1 强调色（accent）。
- accent 是"视觉钩子"，只出现在主标题关键词、价格、核心符号上，不能泛滥。
- 暖色产品（养生/食品/家居）用暖灰底+暖橙 accent；冷色产品（数码/科技）用深蓝底+霓虹蓝 accent。

## 五、构图模式（Layout System）

5 种专业构图，**按 Concept 选一种**，禁止混搭路线：

### L1 · 对称聚焦（Symmetric Focus）
- 产品居中，文字居中对称分布上下/左右。
- 适合：高端、仪式感、产品本身是视觉主角。
- 视线：中心放射。

### L2 · 非对称对角线（Diagonal）
- 产品占下方/右下，文字块占左上，形成对角线张力。
- 适合：有动感、想打破呆板的产品。
- 视线：左上→右下 引导。常加一条斜向辅助线/色块强化。

### L3 · 满版前景遮挡（Full-bleed Overlap）
- 背景铺满，产品放大占 60%+ 画幅，文字压在产品或背景上（靠 surface 色块/遮罩保证可读）。
- 适合：美食、解构、冲击力、大片感。
- 视线：满版沉浸。

### L4 · 三分法叙事（Rule of Thirds）
- 画面分三栏/三区：一区放概念符号/大字，一区放产品，一区放利益点。
- 适合：信息稍多、需要叙事节奏的海报。
- 视线：Z 字或 F 字扫描。

### L5 · 色块切割（Block Cut）
- 用 2–3 个纯色/渐变色块把画面切成几何区块（如左 1/3 深底放标题，右 2/3 浅底放产品）。
- 适合：极简、 editorial、品牌调性。
- 视线：色块引导分区阅读。

## 六、装饰元素库（Decor Kit）

装饰必须为 Concept 服务，禁止随机碎片。**每个装饰都要"有理由"**。

| 元素 | 画法 | 适用 Concept | 注意 |
|------|------|--------------|------|
| **色块 Block** | 纯色/渐变矩形，承载文字或分割 | 色块切割/强调 | 不超 2 块，色取 Token |
| **分割线 Rule** | 1–3px 横线/竖线，可带 accent | 区块分隔/标题下划线 | 对齐栅格，不漂浮 |
| **胶囊标签 Pill** | 圆角矩形+小字，如「新品」「限时」 | 标签/卖点 | 字距拉开，accent 描边或填充 |
| **价格爆炸贴 Burst** | 星形/圆形爆炸，内填价格 | 促销 | 只放一处，accent 填充 |
| **印章 Seal** | 圆/方印章，中式（如「暖」「养」） | 新中式/国潮 | 朱红，置于角，不挡主体 |
| **几何 Geometric** | 圆/三角/弧，置于主体底层 | 极简/科技 | 低密度，1–2 个 |
| **概念符号 Symbol** | 为 Concept 定制的视觉符号（经络线/温度/光） | 所有 | **最强装饰**，优先于通用元素 |
| **纹理 Texture** | 颗粒噪点/光晕/纸张感 | 全风格提质感 | 极低透明度，不抢戏 |

**反 AI 拼贴清单（出现即判业余）**：
- ❌ 随机漂浮圆点、星光、碎片
- ❌ 无意义渐变光斑/过度 bloom
- ❌ 与主题无关图标堆叠
- ❌ 文字描边+投影+渐变三重叠加
- ❌ 产品悬浮无阴影

**正确做法**：装饰 = 引导视线 / 分割区块 / 点明主题 / 强化 Concept，四选一或组合，绝不"为了好看而加"。

## 七、质感背景生成（Background Texture）

纯渐变 = 业余感来源之一。专业背景至少叠一层质感：

1. **渐变基底**：双色/三色同色系渐变（用 Token）。
2. **光晕 Glow**：1–2 处径向光晕（accent 或浅色，透明度 15–30%），制造空间。
3. **颗粒 Grain**：全图叠加 3–6% 噪点（用随机微点或半透明噪声层），去"数码塑料感"。
4. **几何/色块**：按 Layout 叠加色块或弧线。
5. **概念符号**：Concept 专属符号（如经络发光线）作为背景层。

## 八、交付自检（Professional Checklist）

1. ☐ 有清晰 Concept（一句话能说清）？
2. ☐ 元素全吸附栅格，无自由散落？
3. ☐ 字阶 Display→Body 落差 ≥1.5 倍？
4. ☐ 配色 ≤3 主色 + 1 accent，accent 只用于 1–2 处？
5. ☐ 构图模式统一，无路线混搭？
6. ☐ 装饰都为 Concept 服务，无随机碎片？
7. ☐ 背景有质感层（光晕/颗粒/色块其一）？
8. ☐ 文字全在画布内、距边 ≥6%、可读（遮罩/色块保证）？
9. ☐ 字体来自 font-guide 清单，无版权风险？
10. ☐ 多比例下文字/产品重新适配，不溢出不拥挤？

10 项全过 = 专业级。
