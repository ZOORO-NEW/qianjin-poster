# 风格库 · Style Library

> 每种风格 = 一套完整的"配色 Token + 字体组合 + 装饰元素 + 构图偏好 + 文案调性"。
> 技能根据用户产品/行业/基调，自动匹配最贴合的风格（或让用户指定）。所有 Token 定义见 `design-system.md`。

---

## S1 · 新中式养生（Neo-Chinese Wellness）⭐养生/理疗/茶/滋补首选

- **Concept 倾向**：把"调理/温热/经络/自然"做成视觉符号（经络发光线、足底穴位图、水墨笔触、暖光）。

- **配色 Token**（v2.3 详见 `color-system.md`）：
  - `--bg` `#EFEAE1`（宣纸白，饱和 30%）/ `--bg-2` `#DCD2C0`
  - `--ink` `#1B2434`（冷调深墨）/ `--ink-soft` `#667080`
  - `--accent` `#2E4A7D`（**鸢尾蓝**，跨色域主强调）
  - `--accent2` `#B23A2E`（朱红，仅印章/经络线）
  - `--surface` `#FAF7F1`
  - **策略**：传统暖米+朱红平庸，改冷调鸢尾蓝拉开 180°，朱红退为点缀。
- **字体**：标题思源宋体（衬线·书卷气）；印章用思源宋黑；英文 Playfair Display。
- **装饰**：朱红印章（「暖」「养」「经络」）、经络发光线（细金/橙线）、水墨笔触、足底穴位线稿（极淡）。
- **构图**：L1 对称聚焦 或 L5 色块切割（左深褐标题区 + 右米白产品区）。
- **文案调性**：文言韵律 + 现代痛点（"寒从足底起""暖暖的更健康"）。

## S2 · 国潮（Guochao）

- **Concept 倾向**：传统符号现代化（祥云、回纹、仙鹤、霓虹故宫红）。

- **配色 Token**：
  - `--bg` `#1C1526`（深紫黑）/ `--bg-2` `#33254A`
  - `--ink` `#F3E4C4`（描金米）/ `--ink-soft` `#9A8256`
  - `--accent` `#E8B65A`（描金，133°）/ `--accent2` `#C63B3B`（中国红）
  - `--surface` `#2A1F3A`
  - **策略**：冷暗底衬暖金；ink-soft 必须压暗，否则与金色明度撞齐。
- **字体**：标题得意黑 Smiley Sans（窄体·力量）；英文 Montserrat Black。
- **装饰**：祥云/回纹几何、描金描边、霓虹外发光（克制）。
- **构图**：L3 满版前景 或 L5 色块切割。
- **文案调性**：大气、文化自信、短句口号。

## S3 · 极简科技（Minimal Tech）

- **Concept 倾向**：用"留白+精密"表达高端，产品即主角，少即是多。

- **配色 Token**：
  - `--bg` `#12141A`（近黑）/ `--bg-2` `#1E222C`
  - `--ink` `#F2F5F8` / `--ink-soft` `#767F8E`
  - `--accent` `#4AE3A4`（**荧光青**，71°）/ `--accent2` `#4A9EFF`
  - `--surface` `#1A1D25`
  - **策略**：旧版深空蓝+霓虹蓝=5°撞色糊成一片，改青绿后跨色域 71°。
- **字体**：标题思源黑体 Heavy；英文数字 Montserrat Black（价格/参数用）。
- **装饰**：细网格线、单几何圆/弧、冷光晕、技术参数小字（Caption 拉开字距）。
- **构图**：L1 对称聚焦 或 L4 三分法（大字+产品+参数）。
- **文案调性**：参数化、冷峻、利益点用数字（"提速 40%"）。

## S4 · 暖心家居（Warm Home）

- **Concept 倾向**：家的温度、松弛感，暖光与柔软材质。

- **配色 Token**：
  - `--bg` `#F2EDE4`（奶白）/ `--bg-2` `#E0D6C6`
  - `--ink` `#223028`（墨绿黑）/ `--ink-soft` `#6E7D75`
  - `--accent` `#B85C3A`（陶土橘）/ `--accent2` `#3D5A50`（墨绿，121°）
  - `--surface` `#FCFAF5`
  - **策略**：暖色域内色相差小正常，用 accent2 墨绿拉开第二层次。
- **字体**：标题站酷快乐体（圆体·亲和）；英文 Montserrat。
- **装饰**：柔和暖光晕、圆角色块、生活化小插画符号（极简线条）。
- **构图**：L2 非对称对角线（产品右下、文字左上）。
- **文案调性**：口语、陪伴感、场景化（"下班后的 20 分钟"）。

## S5 · 美食诱惑（Food Temptation）

- **Concept 倾向**：食欲、材质特写（拉丝/光泽/水珠/碎屑）、满版沉浸。

- **配色 Token**：
  - `--bg` `#1F1712`（深巧克力）/ `--bg-2` `#382519`
  - `--ink` `#FAF0E2` / `--ink-soft` `#BC9C7C`
  - `--accent` `#E39B1F`（明黄）/ `--accent2` `#C0452A`（砖红）
  - `--surface` `#2E2018`
  - **策略**：同色域内不硬拉色相，靠明度阶梯拉开（深底10 → 中调61 → 亮黄78）。
- **字体**：标题站酷快乐体 / 庆科黄油体（圆体·诱人）；英文 Montserrat Black。
- **装饰**：水珠/蒸汽线、材质高光、满版深色衬底。
- **构图**：L3 满版前景遮挡（产品放大 60%+）。
- **文案调性**：感官动词（"爆汁""脆""香"）、短促有力。

## S6 · 促销炸裂（Promo Blast）

- **Concept 倾向**：划算感、紧迫感，信息密集但分区清晰。

- **配色 Token**：
  - `--bg` `#C81E1E`（正红）/ `--bg-2` `#9E1414`
  - `--ink` `#FFFFFF` / `--ink-soft` `#FFE0D6`
  - `--accent` `#FFC72C`（亮黄）/ `--accent2` `#7A1410`（深红棕）
  - `--surface` `#FFFFFF`
  - **策略**：全系统唯一允许高饱和的爆色风格；白字对比 4.9:1（旧版 3.3:1 不达标）。
- **字体**：标题得意黑（窄体·冲击）；价格数字同用得意黑；英文 Montserrat Black。
- **装饰**：价格爆炸贴（金黄填充）、胶囊标签（「限时」「直降」）、斜向箭头/色带。
- **构图**：L4 三分法 或 L5 色块切割（红底标题 + 白底价格区）。
- **文案调性**：数字冲击（"直降 ¥200""第二件半价"）、动词催促。

## S7 · 杂志封面（Editorial）

- **Concept 倾向**：刊物感、瑞士极简、巨型字体、细节信息。

- **配色 Token**：
  - `--bg` `#F1EEE7`（宣纸白）/ `--bg-2` `#E2DDD1`
  - `--ink` `#12141A` / `--ink-soft` `#6B7078`
  - `--accent` `#2B4C8C`（鸢尾蓝，178°）/ `--accent2` `#B23A2E`
  - `--surface` `#FFFFFF`
  - **策略**：编辑风标准配色，178° 强对比；ink-soft 须与 accent 拉开明度。
- **字体**：标题思源宋体（衬线·高级）；英文 Playfair Display。
- **装饰**：刊号（NO.26）、条码、四角星芒、辅助小字、纸张颗粒、巨型字体拖影。
- **构图**：L5 色块切割 或 L1 对称。
- **文案调性**：主张式、克制、像真实刊物封面文案。

## 风格匹配速查

| 产品/行业 | 首选风格 |
|-----------|----------|
| 养生/理疗/滋补/茶/中药 | **S1 新中式养生** |
| 文创/非遗/传统食品/国货 | S2 国潮 |
| 数码/家电/科技硬件 | S3 极简科技 |
| 家居/小家电/母婴/日用 | S4 暖心家居 |
| 食品/饮品/餐饮 | S5 美食诱惑 |
| 大促/清仓/折扣/电商活动 | S6 促销炸裂 |
| 品牌种草/人物/IP/态度 | S7 杂志封面 |

> 同一产品可叠加：如养生仪用 S1 基调，大促时切 S6 配色但保留 S1 的印章/经络符号，形成"家族感"。
