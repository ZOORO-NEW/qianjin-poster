# 国潮美食插画海报合成器

> `scripts/compose_guochao_food.py` —— 给「生图产出插画底图」叠加国潮装饰与文字层。
> 与 `compose_poster.py` 的分工：后者做**产品海报**（有实拍产品图），本脚本做**美食/国潮插画海报**（满版插画 + 装饰框 + 书法文字）。

---

## 一、为什么需要它

国潮美食插画海报的难点不在画面（混元生图能出高质量插画底图），而在**装饰与文字层**：

- 书法艺术大字 + 描边 + 外发光
- 拼音小字（竖排）
- 木质挂牌（挂绳 + 木纹 + 内描边）
- 弧形木框 + 三卖点

这些**混元生图做不出来**（生图模型写不对中文字），必须靠 PIL 精确合成。

---

## 二、标准流程

```bash
# 1. 生图（混元）—— 提示词要强调「顶部左侧留空白」「插画质感」
# 2. 去水印 —— buddy-image-processing erase
# 3. 合成装饰与文字
python scripts/compose_guochao_food.py \
  --bg base.png --out final.png \
  --title 螺蛳粉 --pinyin "LUO SI FEN" \
  --plaque 古法秘制 \
  --s1 "骨汤慢熬 鲜爽够味" \
  --s2 "配料丰富 分量十足" \
  --s3 "地道风味 一口上头"
```

## 二·五、底图生图提示词模板（决定食欲感的关键）

**食欲感不来自后期，来自底图构图。** 对比实测有效的写法：

```
【主体】画面中央是一双从右上角斜向伸入的木筷，夹起一大把瀑布状的金黄米粉
        面条垂坠而下，面条占据了画面中央约四成面积，是绝对主体。
        面条饱满油亮，橙红油汤均匀挂在面条表面并顺着面条缓缓滴落。
【容器】画面下方是一口黑色砂锅，锅沿可见，锅内盛满螺蛳粉。
【配料环绕】画面四周密布散落的配料，形成一圈围绕主体的框景，量感充足。
【色调】整体统一为暖橙红色调，汤汁橙红油亮，饱和度高。
画面左上方与底部留出空白区域供后期添加文字。
```

### 食欲感的四条铁律

| 要素 | ❌ 错的写法 | ✅ 对的写法 |
|---|---|---|
| **酱汁位置** | 「汤汁从粉面间飞溅而下」「溅起油花」 | 「油汤**挂在**面条表面并**顺着面条缓缓滴落**」 |
| **主体占比** | 面条偏小，汤汁与配料抢戏 | 面条占画面 **约四成**，明确写「绝对主体」 |
| **器物动势** | 筷子近乎垂直 | 「从**右上角斜向伸入**」，动势强 |
| **配料分布** | 稀疏散落 | 「**密布环绕**主体形成框景」，量感充足 |

**核心原理**：食物摄影的铁律是「**酱汁要挂在主体上，不要在空中乱飞**」。
飞溅的汤汁视觉上是「脏」；挂在面条上、缓缓滴落才是「香」与「润」。

### 即梦 vs 混元（实测差异）

同一提示词下，即梦更「有食欲感」，差异不在画质而在**提示词的写法**：
- 即梦对「主体占比」「框景」这类构图指令响应更好 → 提示词要**显式指定占比数字**
- 混元对「飞溅」类指令响应过强 → 要改写成「挂在表面缓缓滴落」反向约束

**对策**：把构图写死（占比、角度、密布），并用反向表述抑制过度飞溅。

## 三、字体选择（关键坑）

| 用途 | 字体 | 原因 |
|---|---|---|
| 书法大字 | `ZCOOLKuaiLe.ttf` | 站酷快乐体，有国潮书法笔意 |
| 拼音 | `PlayfairDisplay.ttf` / `BebasNeue.ttf` | 拉丁字母衬线/ condensed |
| 卖点、挂牌文字 | **`NotoSansSC-Bold.otf`** | ⚠️ 见下方坑 |
| 大字描边 | — | 深墨 `#1A0C04`，宽度 4-7px |

### ⚠️ 坑：SourceHanSerifSC-Black 缺 ASCII 空格与中点

**现象**：用思源宋体 Black 渲染 `骨汤慢熬 鲜爽够味`，中间的空格会渲染成**空心方框**。

**原因**：该字体子集不含 U+0020 和 U+00B7。

**修法**：**所有含空格/中点的文字一律用 `NotoSansSC-Bold.otf`**，思源宋体只用于纯中文大字。

验证脚本：
```python
from PIL import ImageFont
f = ImageFont.truetype(".../SourceHanSerifSC-Black.ttf", 40)
# 检查字符是否有字形
import fontTools  # 或直接渲染到图上看
```

## 四、设计规范（对齐专业国潮物料）

### 配色（暗夜暖金体系）
```python
INK       = "#2B1408"   # 焦糖墨（主文字）
INK_DEEP  = "#1A0C04"   # 深墨（描边）
GOLD      = "#E8B65A"   # 描金
RED       = "#C63B3B"   # 朱红
CREAM     = "#FFF4DC"   # 米白（文字底衬）
WOOD_D    = "#6B4423"   # 木牌深
WOOD_L    = "#A5713C"   # 木牌浅
WOOD_E    = "#4A2D14"   # 木牌描边
```

### 文字必须「三重保障」
压在 busy 的插画背景上，单层文字一定糊。每处文字至少两层：

1. **底衬**（半透明米白/深墨圆角块）
2. **描边**（深墨 4-7px）
3. **可选外发光**（描金色，GaussianBlur）

### 布局要点（实测踩坑）
- **拼音竖排**：横排会被大字墨迹压糊；竖排放在大字右侧 + 深色底衬
- **卖点横排一行**：沿弧线摆放必然叠字（弧线两端上翘区会互相挤压）
- **弧框要三层描金**：单层深木框贴在深背景上看不见 —— 外描金 + 深木 + 内描金
- **上下压暗**：顶部 42% / 底部 30% 做渐变压暗，给文字让出可读底

## 五、常见错误对照

| 症状 | 病因 | 修法 |
|---|---|---|
| 文字间出现空心方框 | 字体缺该字符字形 | 换 NotoSansSC-Bold |
| 拼音糊在大字上 | 横排 + 无底衬 | 改竖排 + 加深色底衬 + 右移 |
| 三卖点互相重叠 | 沿弧线按角度摆放 | 改一行横排 |
| 弧形木框看不见 | 单层深木贴深背景 | 三层描金结构 |
| 文字压住主体 | 无压暗层 | 上下渐变压暗 |
| 卖点被画幅切断 | 弧线端点超出画布 | 调小 `--frame-y`（框上移） |
| 卖点与配料混在一起 | 半透明米白底衬不够强 | 改「深墨底衬 + 描金边」（脚本已内置） |
| 底图主体偏下压住卖点 | `--frame-y` 默认值不适配该底图 | 微调 `--frame-y`，生成多版对比 |

## 六、参数速查

```bash
--bg            底图路径（生图+去水印后的图）
--out           输出路径
--title         书法大字内容
--pinyin        拼音（竖排渲染，空格自动跳过）
--plaque        右上角木牌文字
--s1/--s2/--s3  三条卖点
--title-size    大字字号（默认 168，按画布高度 1536 基准）
--dark          上下压暗强度（0~1，默认 0.30）
--frame-y       弧形木框基准位置（距底边比例，默认 0.125）。
                底图主体位置不同需微调：主体偏下则调大（框下移），
                主体偏上则调小。生成 2~3 个值对比后取最优。
```

脚本内所有尺寸按 `sc = H / 1536` 缩放，换画幅（如 1080×1920）会自动适配。
