# 配色系统（v2.3 重构）

> 高级感不来自装饰堆砌，来自**底色退让 + 强调色跳脱 + 明度分层**三者协同。
> 本文档是可执行规范，改配色前先读「诊断方法」，改完必须跑「自检清单」。

---

## 一、诊断方法：先量化，再动手

凭感觉调配色会来回摇摆。用下面三组数据定位问题，比肉眼判断准得多。

### 1.1 色相跨度检测（撞色检测）

计算背景与强调色的**色相差**：

```
diff = |hue_bg - hue_accent|，取 min(diff, 360 - diff)
```

| 判定 | 阈值 | 症状 |
|---|---|---|
| 撞色 | diff < 25° | 底色与强调色挤在同一色域，**发闷、脏、没呼吸** |
| 偏弱 | 25° ≤ diff < 60° | 对比不足，强调色"跳不出来" |
| 健康 | diff ≥ 60° | 层次分明 |

**注意**：低饱和背景（如米色 `#EFEAE1` 饱和 30%）的色相值接近 0°，任何暖色 accent 都会被误判为"撞色"。此时应看**明度差**而非色相差。

### 1.2 明度阶梯检测（高级感的真正来源）

把四级元素（背景 / 正文 / 次文 / 强调）转成 HSL 的 L 值，排序后看**间隔是否均匀**：

```
L = sorted([L_bg, L_soft, L_ink, L_accent])
gaps = [L[i+1] - L[i] for i in range(3)]
```

- 四个 L 值**单调分离、每级 gap > 6** → 层级清晰
- 出现 `gap < 5` → 强调色与次强调色明度撞在一起，印章/分割线分不出层次，**必须调整**

同时要求 `|L_ink - L_bg| ≥ 55`（底与正文的强对比决定"纸感"与可读性）。

### 1.3 对比度检测（WCAG）

| 关系 | 最低要求 | 用途 |
|---|---|---|
| `ink / bg` | ≥ 4.5:1 | 正文可读性（AA 级） |
| `ink_soft / bg` | ≥ 3.0:1 | 次要文字 |
| `accent / bg` | ≥ 2.5:1 | 强调元素（印章、价格贴）|

低于阈值不是"不好看"，是**看不清**——印刷后更糟。

## 二、配色五原则

1. **底色低饱和（≤30%）**——底色的角色是"纸/底"，不是主角。饱和的底色会和内容抢注意力。
2. **主强调色负责跳脱**——与底色形成明确的**色相或明度反差**，二者必居其一。
3. **次强调色 `accent2` 负责第二锚点**——用于印章/经络线等点缀，与主强调色拉开层次（色相或明度至少差一档）。
4. **文字层级靠明度阶梯**——`ink`(最深) > `ink_soft`(中) > 底色(浅)。不要指望色相做层级。
5. **饱和度纪律**——除 S6 促销（唯一允许爆色），强调色饱和控制在 **45-80%**。两个满饱和色相撞 = 视觉噪音。

## 三、七套配色 Token

### S1 新中式养生 —— 宣纸白 × 鸢尾蓝
| Token | 色值 | 说明 |
|---|---|---|
| `bg` | `#EFEAE1` | 宣纸白，饱和 30% |
| `bg2` | `#DCD2C0` | 渐变暗部 |
| `ink` | `#1B2434` | 冷调深墨蓝黑 |
| `ink_soft` | `#667080` | 灰蓝次文 |
| `accent` | `#2E4A7D` | **鸢尾蓝**，跨色域主强调 |
| `accent2` | `#B23A2E` | 朱红，仅印章/经络线 |
| `surface` | `#FAF7F1` | 衬底 |

**策略**：传统"暖米+朱红"安全但平庸缺张力。改用冷调鸢尾蓝后立刻有了现代感，朱红退为点缀。

### S2 国潮 —— 深紫底 × 描金
| Token | 色值 |
|---|---|
| `bg` / `bg2` | `#1C1526` / `#33254A` |
| `ink` / `ink_soft` | `#F3E4C4` / `#9A8256` |
| `accent` | `#E8B65A`（描金，133°） |
| `accent2` | `#C63B3B`（中国红） |

**策略**：冷暗底衬暖金。`ink_soft` 必须压暗，否则与金色明度撞齐。

### S3 极简科技 —— 近黑底 × 荧光青
| Token | 色值 |
|---|---|
| `bg` / `bg2` | `#12141A` / `#1E222C` |

| `accent2` | `#4A9EFF` |

**策略**：旧版深空蓝配霓虹蓝 = 5° 撞色，肉眼看着"糊成一片"。改青绿后跨色域 71°，科技张力立现。

### S4 暖心家居 —— 奶白 × 陶土橘 + 墨绿次强调
| Token | 色值 |
|---|---|

| `accent` | `#B85C3A`（陶土橘） |
| `accent2` | `#3D5A50`（墨绿，121°） |

**策略**：暖色域内色相差小是正常的，用 `accent2` 墨绿拉开第二层次。

### S5 美食诱惑 —— 深巧克力 × 明黄
| Token | 色值 |
|---|---|
| `bg` / `bg2` | `#1F1712` / `#382519` |
| `ink` / `ink_soft` | `#FAF0E2` / `#BC9C7C` |
| `accent` | `#E39B1F`（明黄） |
| `accent2` | `#C0452A`（砖红） |

**策略**：同色域（暖橙）内不硬拉色相，靠**明度阶梯**拉开：深底(10) → 中调(61) → 亮黄(78)。

### S6 促销炸裂 —— 正红 × 亮黄
| Token | 色值 |
|---|---|
| `bg` / `bg2` | `#C81E1E` / `#9E1414` |
| `ink` / `ink_soft` | `#FFFFFF` / `#FFE0D6` |
| `accent` | `#FFC72C`（亮黄） |
| `accent2` | `#7A1410`（深红棕） |

**策略**：全系统**唯一允许高饱和**的爆色风格。白字在红底上对比 4.9:1（旧版 3.3:1 不达标）。`accent2` 用深红棕而非纯黑——纯黑在红底上发闷。

### S7 杂志封面 —— 宣纸白 × 鸢尾蓝
| Token | 色值 |
|---|---|
| `bg` / `bg2` | `#F1EEE7` / `#E2DDD1` |
| `ink` / `ink_soft` | `#12141A` / `#6B7078` |
| `accent` | `#2B4C8C`（鸢尾蓝，178°） |
| `accent2` | `#B23A2E` |

**策略**：编辑风标准配色，178° 强对比。`ink_soft` 必须与 `accent` 拉开明度（36 vs 36 是旧版 bug，已修为 36 vs 25）。

## 四、常见错误对照

| 症状 | 病因 | 修法 |
|---|---|---|
| 整体发闷、脏 | accent 与 bg 色相差 < 25° | 换跨色域强调色，或改用明度反差 |
| 印章/分割线分不清 | `accent` 与 `ink_soft` 明度差 < 5 | 压暗 `ink_soft` 或提亮 `accent` |
| 远看糊成一片 | 正文对比 < 4.5:1 | 加深 `ink` 或提亮 `bg` |
| 两个颜色都很跳 | 两个满饱和色相撞 | 收敛其一到 45-70% 饱和 |
| 底色抢戏 | `bg` 饱和 > 30% | 降饱和，底色退为"纸" |
| 暖色系显得土 | 底色与强调色同处暖橙域 | 用 `accent2` 引入第三色（墨绿/深棕） |

## 五、自检清单

改完配色，逐项打勾：

- [ ] `accent` 与 `bg` 色相差 ≥ 60°，或明度差 ≥ 40
- [ ] `accent` 与 `ink_soft` 明度差 ≥ 8（印章/分割线要能分层）
- [ ] `ink` 与 `bg` 对比度 ≥ 4.5:1
- [ ] `ink_soft` 与 `bg` 对比度 ≥ 3.0:1
- [ ] `bg` 饱和度 ≤ 30%（S6 除外）
- [ ] `accent` 饱和度 45-80%（S6 除外）
- [ ] 出图后目视确认：印章、分割线、价格贴三者在同一张图上能分辨

## 六、Token 增补指南

新增风格时：

1. 先确定**对比策略**（是走色相差还是明度差），不要随手挑色
2. 在 `STYLES` 字典里写全 6 个 Token：`bg` / `bg2` / `ink` / `ink_soft` / `accent` / `accent2` / `surface`
3. 附 `palette_note` 字段说明配色理由（便于后续调优时回溯）
4. 同步更新本文件第三节与 `references/styles.md`
5. 跑 1.1/1.2/1.3 三项检测，全部达标再用
