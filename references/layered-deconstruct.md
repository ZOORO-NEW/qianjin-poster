# 逐层悬浮解构（compose_layered.py）

> **这是本技能唯一需要「多步」的场景。**
> 原因：生图模型排不准层间精确位置与标签对齐。

---

## 一、什么情况下才用

| 需求 | 用什么 |
|---|---|
| 常规海报（促销/餐饮/美妆/节日） | **一次生图**，不要用本引擎 |
| 配料分层图 / 产品结构拆解 / 爆炸图 | ✅ 本引擎 |
| 层间要对齐标签、要精确控制位置 | ✅ 本引擎 |

**判断标准**：如果用户说「一次出图就行」，就别用引擎。

---

## 二、工作流

```bash
# ① 生图各部件（透明 PNG）
#    提示词要点：「X 部件特写，悬浮于纯黑背景，产品级渲染，无文字无水印」
#    → 每张跑 erase 去水印 → matting 抠透明

# ② 合成
python scripts/compose_layered.py \
  --bg base.png --out final.png --style S3 --ratio 3:4 --layout L1 \
  --layer "屏幕.png@0.66,0.40,0.14" \
  --layer "机身.png@0.62,0.555,0.25" \
  --layer "摄像头.png@0.69,0.685,0.125" \
  --callout-style horizontal --callout-align auto \
  --callout "阔屏总成@0.26,0,1,l" \
  --callout "6.75英寸直屏@0.26,0,2,l" \
  --callout "潜望长焦@0.26,0,3,l" \
  --title "Mate 90 逐层解构" --subtitle "六层精密 层层可见"
```

---

## 三、核心参数

### `--layer`（部件）
```
path@cx,cy,scale
```
- `cx,cy` 中心点（占画幅比例 0~1）
- `scale` 相对短边缩放（0.1~0.8）
- **可多次传入**，叠放顺序 = 传入顺序（先传的在下层）

### `--callout`（层标签）
```
文字@cx,cy,层序号,方向
```
- `层序号`：对应第几个 `--layer`（从 1 起）
- `方向`：`l` 左侧 / `r` 右侧
- **`horizontal` 样式下 cy 会被自动对齐到该层垂直中心**，故可传 0

### `--callout-style`
| 值 | 效果 | 适用 |
|---|---|---|
| `horizontal` | 纯水平引线 + 端点圆点 | **逐层垂直悬浮（推荐）** |
| `leader` | 折线引导 | 部件位置分散 |

### `--callout-align`
- `auto`（默认）：标签自动对齐层中心（配 `horizontal` 生效）
- `free`：用 `@cy` 自由定位

## 四、逐层布局的参数规律

```
层位置从上往下：cy = 0.40, 0.55, 0.68, 0.80, 0.92
                 间距 ≈ 0.13，底部留 0.08
部件大小递减：    scale = 0.14, 0.25, 0.13, 0.15, 0.14
                 主部件（机身）最大，配件层次之
标签列位置：      cx = 0.26（左侧），方向 l
```

**要点**：
- **顶部 0.04~0.40H 留给标题**，层堆从 0.40H 开始
- 标签列占左侧 0~0.35W，层堆占中间 0.4~0.85W
- 层间距要**均匀**，不均匀会显得杂乱

## 五、引擎自动处理的事

| 问题 | 引擎行为 |
|---|---|
| 标签越出画布 | 左右缘自动钳制回画布内 |
| 多条线指同一层 | 自动分配不同纵向锚点，不重叠 |
| 标签与价格贴冲突 | 价格贴轮询候选位避让标签 |
| 文字被层堆压住 | 文字天花板压到「最上层上缘 - 34px」 |
| 比例不符 | 自动扩边（目标更宽→左右扩，更高→上下扩） |
| 水印 | 不会处理，需自己先跑 erase |

## 七、实战案例（已验证）

**华为 Mate 90 五层解构**（2026-10）：
- 层：屏幕 / 机身 / 摄像头 / 主板 / 电池
- 风格 S3 极简科技，3:4
- 结果：标题+副标题+5 层标签+价格贴全保留，**零省略**
- 这个案例即梦做不出来（排不准层间位置与标签对齐）
