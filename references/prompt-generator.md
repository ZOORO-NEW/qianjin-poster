# 海报提示词生成 · prompt-generator

> 本文件让 qianjin-poster 在"直接 PIL 出图"之外，还能**生成可粘贴到 AI 生图平台的提示词**。适配：元宝（腾讯）、即梦（字节）、豆包（字节）。方法论提炼自专业海报提示词范式，仅抽象结构，不照搬任何原文案。

---

## 一、什么时候用"提示词"，什么时候用"PIL 直出"

| 路线 | 适合 | 不适合 |
|------|------|--------|
| **提示词（即梦/元宝/豆包）** | 追求写实摄影感、光影氛围、材质细节、创意构图；用户愿意去平台生成 | 需要精确排版、强制嵌入品牌 logo、指定免费字体、多比例严格统一 |
| **PIL 直出（compose_poster.py）** | 抠产品图、加企业 logo、控字体版权、系列尺寸一键出 | 写实质感/复杂光影/人物摄影感（PIL 难做） |

**原则**：用户要"氛围感大片"→给提示词；用户要"贴上自家 logo 的促销图"→PIL 直出。两者可组合：用提示词生成背景氛围图，再 PIL 合成 logo 与文案。

---

## 二、通用提示词公式（11 段，顺序可调）

```
[1 画面类型与比例] + [2 风格定位] + [3 主体描述] + [4 场景氛围]
+ [5 光影与材质] + [6 构图与版式] + [7 配色方案]
+ [8 标题文案(中文主标+英文/小字副标)] + [9 细节与质感]
+ [10 负面词(negative)] + [11 平台备注]
```

**逐段写法要点**
1. **画面类型与比例**：竖版 3:4 / 9:16、横版 16:9、方形 1:1；满版构图（无外框无留白）或留白构图。
2. **风格定位**：未来科技 / 赛博朋克 / 禅意极简 / 日式留白 / 电商写实摄影 / 暗黑电竞 / 户外 rugged / 运动活力 / 极简未来 / 美式黑金促销 / 国潮 / 莫兰迪 / 瑞士极简杂志 / 悬浮解构 / 人物肖像 / 创意双关。
3. **主体描述**：产品/人物/物品的具体形态、材质、颜色、状态（悬浮/斜放/立于某台面）。**锚定用户原图**：若用户给了产品图，写明"以上传图片为主要参考，保留品类/材质/比例，不增减元素"。
4. **场景氛围**：背景渐变方向、环境（太空舱/峡谷日落/京都春日/直播间/超市堆头）、情绪（冷冽/温暖/动感/静谧）。
5. **光影与材质**：冷光漫反射 / RGB 自发光 / 侧光硬朗 / 柔光无影 / 体积光 / 一道光勾勒轮廓；材质（磨砂/拉丝金属/编织/硅胶/玻璃折射）。
6. **构图与版式**：主体居中对称 / 黄金分割 / 三层结构（顶部品牌+中间主标+底部商品矩阵）/ 前后遮挡（人物压字）。
7. **配色方案**：主色+辅色+点缀，写明色值更佳（如 深空黑 `#0B1E3F` + 霓虹蓝 `#3A6FF7`）。
8. **标题文案**：主标题（≤10 字，口语/有冲突）+ 副标题/英文小字（如品牌名、SLOGAN）。**文案要短、字号大、对比强**，避免长句（生图平台文字渲染易乱码）。
9. **细节与质感**：写实主义 / 商业大片 / 8K / 大师级摄影 / 极致清晰度 / 颗粒感光尘。
10. **负面词**：见第三节。
11. **平台备注**：见第四节。

---

## 三、负面词库（negative prompt）

**通用**：文字乱码、变形、多余手指、低分辨率、模糊、水印、廉价拼贴感、卡通 CG、重复元素、不需要的 Logo、杂乱背景。

**分风格追加**
- 写实电商：`不要插画风、不要 3D 卡通、不要过度磨皮`
- 高级留白：`不要装饰堆砌、不要边框、不要渐变光斑`
- 赛博/电竞：`不要重影、不要双脸、不要廉价霓虹`
- 人物肖像：`不要畸变、不要多手多眼、不要过度滤镜`

---

## 四、平台适配（元宝 / 即梦 / 豆包）

三者均**原生支持中文提示词**，可直接写中文，无需翻译英文。

| 平台 | 特长 | 提示词建议 |
|------|------|-----------|
| **即梦**（字节） | 电商促销、中文文案准确、中文文字渲染较强 | 文案可写具体（如"双11 全场5折"）；善用"电商风格/8K/商业大片"；比例优先 9:16 竖版 |
| **元宝**（腾讯） | 通用创意、国风、写实均衡 | 结构清晰分段；国潮/留白类表现好；控制单张文案 ≤12 字 |
| **豆包**（字节） | 通用、人物/场景 | 与即梦同源，中文友好；人物肖像类可强调"面部清晰、真实肤感" |

**跨平台通用铁律**
- 文案务必短（主标 ≤10 字），长句必乱码。
- 若要精确品牌字，生图后仍需 PIL 二次合成 logo（见 SKILL.md 第七节）。
- 比例写明，避免平台默认裁切。

## 六、生成示例（占位结构，落地需据产品重写，禁止照搬）

> 以下为"蓝牙耳机·未来科技风·即梦"的结构示范，仅展示公式如何拼装，**实际文案须为用户产品重新构思**：

```
竖版 3:4 满版构图，未来科技风格产品海报；［产品主体描述，据用户产品重写］
悬浮于画面中央，周围漂浮半透明蓝色音波环与银色光点；深空灰到黑色渐变背景，
无重力太空舱氛围；［材质与光影描述］；极简未来风，
标题"［主标题≤10字，按产品重写］"小字"［英文SLOGAN］"；商业大片质感，8K，细节锐利。
--negative：文字乱码、低分辨率、水印、卡通、多余Logo
--平台：即梦，竖版9:16，文案保持简短
```

> 注：上方为**结构占位**，方括号内容必须为用户实际产品重新构思，禁止直接套用任何参考文章的原文案。

调用脚本生成（示例参数为占位，落地需替换）：

```bash
python scripts/gen_prompt.py \
  --ratio "竖版3:4" --style "未来科技" \
  --subject "［产品主体描述］" \
  --scene "深空灰到黑色渐变背景，无重力太空舱氛围" \
  --light "冷光漫反射，金色触点微光" \
  --color "深空黑#0B1E3F + 霓虹蓝#3A6FF7" \
  --title "［主标题≤10字］" --subtitle "［英文SLOGAN］" \
  --quality "商业大片质感，8K，细节锐利" \
  --platform jimeng
```

脚本输出可直接复制的提示词 + 负面词 + 平台备注。
