# 四类海报设计规范 · poster-types

> 本文件为 qianjin-poster 的核心设计模板库。每类海报给出：气质定位、配色方案、文案公式、排版骨架、示例话术。执行时按类型套用，再据产品微调。

---

## 通用：文案提炼方法

无论哪类海报，文案遵循"钩子—证据—行动"三段：

- **主标题**：≤10 字，口语化、有冲突或利益点，禁止空泛形容词。
  - ❌ "优质好物 焕新上市"
  - ✅ "一瓶顶三瓶 省出一台机"
- **副标题**：≤18 字，补场景/人群/证据。
- **利益点**：≤3 条，每条 ≤12 字，用 `|` 分隔，动词开头。
- **行动词**：促销类必带（立即抢/戳下方/领券）；创意类可省略。

## 一、节假日海报

**气质**：喜庆、仪式感、温度。让人想转发、想过节。
**主视觉**：节日符号（灯笼/月饼/雪花/礼盒）+ 产品居中或斜放。
**文案重心**：祝福语 + 限时权益（节日是天然的促销理由）。

### 配色（按节日选）
| 节日 | 主色 | 辅色 | 点缀 |
|------|------|------|------|
| 春节/中秋 | `#C8102E` 中国红 | `#F5E6C8` 暖金 | `#1A1A1A` |
| 圣诞 | `#0B6E4F` 松绿 | `#F4F1DE` 奶白 | `#D4AF37` 金 |
| 618/双11 | `#FF4D4F` 电商红 | `#FFD666` 橙黄 | `#FFFFFF` |
| 端午 | `#1F7A3D` 艾绿 | `#E8B04B` 黄 | `#7A1F1F` |

### 文案公式
- 主标题：`<节日> + <情绪词>` → "中秋团圆 礼遇好味"
- 副标题：`<产品> + <场景>` → "一口酥香 寄给最想的人"
- 利益点：`限时礼盒装|满299减50|赠定制贺卡`

## 二、产品促销海报

**气质**：划算、紧迫、直给。让人立刻想下单。
**主视觉**：产品 + 价格爆炸贴/标签。
**文案重心**：折扣力度 + 利益点（数字优先）。

### 配色
| 场景 | 主色 | 辅色 | 爆炸贴 |
|------|------|------|--------|
| 通用大促 | `#FF4D4F` | `#FFE9E9` | `#FFD666` 黄字 |
| 高端折扣 | `#1A1A1A` | `#F5F5F5` | `#E63946` 红 |
| 清仓 | `#FF6B00` | `#FFF3E0` | `#212121` |

### 文案公式
- 主标题：`<数字/利益>` → "第二件半价" / "直降200"
- 副标题：`<品类> + <人群>` → "全家人的护肤刚需"
- 利益点：`到手价¥99|买一送一|顺丰包邮`
- 行动词：**立即抢 · 限量500份 · 戳下方**

## 三、产品创意海报

**气质**：高级、概念、态度。品牌种草、社媒传播用。
**主视觉**：产品 + 艺术化背景（渐变/光影/留白/负空间）。
**文案重心**：一句话态度（不卖货，立人设）。

### 配色（高级感）
| 风格 | 主色 | 辅色 |
|------|------|------|
| 极简白 | `#FFFFFF` | `#111111` + 一抹 `#C0A062` 金 |
| 暗夜高级 | `#0F0F12` | `#E8E8E8` + `#3A6FF7` 蓝 |
| 莫兰迪 | `#A89B8C` | `#EDE6DD` + `#7C8B6B` |

### 文案公式
- 主标题：`<态度/反常识>` → "好东西 不需要大声说"
- 副标题：`<产品哲学>` → "把时间 留给值得的滋味"
- 利益点：可省略，或 1 条克制点缀。

## 四、产品分层悬浮解构海报

**气质**：商业大片感、动态张力、材质诱惑。餐饮/食品/美妆/数码/组件类均适用——把"完整物体"拆成有节奏的悬浮层次，让人一眼认出是什么，又比照片更有广告质感。
**主视觉**：产品主体居中悬浮 + 组成元素/食材/部件按原层级自然拉开、错落悬浮（可拉伸、飞溅、拉丝）。
**文案重心**：卖点拆解（每个部件对应一个利益点），或大标题点情绪、小字补信息。

### 工作法则（来自专业解构海报范式，已抽象为方法）
1. **锚定原图**：以用户上传图为主要参考，严格保留品类、配料/部件、色彩、比例、纹理。禁止 AI 随意增减原图没有的元素，防止物体失真。
2. **悬浮解构动态**：把整体拆层，做出悬浮、拉伸、飞溅，制造商业大片的动态张力；动态要克制、利落、有冲击力，不是乱飘。
3. **强化材质细节**：重点刻画拉丝、酱汁光泽、脆皮、水珠、碎屑、金属反光等，提升真实感与食欲/质感。
4. **满版 full-bleed 构图**：背景铺满至画布边缘，**无最外层边框、无额外留白**（与"创意留白型"相反，此处要满）。
5. **品牌信息自然融入**：品牌名/logo 置于底部或右下角，排版现代、清晰、精致，不喧宾夺主。

### 配色
| 风格 | 主色 | 辅色 |
|------|------|------|
| 科技蓝 | `#0B1E3F` | `#3A6FF7` + `#8EC5FF` |
| 暖调食欲 | `#2A1206` | `#E8893B` + `#F5D6A8` |
| 纯净白 | `#F5F7FA` | `#1A1A1A` + `#3A6FF7` |
| 暗夜紫 | `#1A0B2E` | `#9B5DE5` + `#F15BB5` |

### 文案公式
- 主标题：`<产品> + <解构视角>` → "拆解 看见每一处讲究"（或情绪型："一口 入魂"）
- 副标题：`<总卖点>` → "8 重结构 重新定义舒适"
- 分层标签（每个部件，可省略，靠视觉说话）：
  - 层1（主体）：`航空铝中框 · 轻至189g`
  - 层2（核心）：`自研芯片 · 提速40%`
  - 层3（细节）：`纳米镀膜 · 抗指纹`

## 五、人物 / 肖像主视觉海报

**气质**：记忆点强、杂志感、代言/人物故事向。适合品牌代言、课程讲师、IP 形象、活动主视觉。
**主视觉**：人物肖像占绝对视觉重心（大头肖像，面部置于视觉黄金区），人物**压在文字层之上**制造前后空间层次，避免画面扁平。
**文案重心**：人设/主张一句话 + 分层辅助信息。

### 工作法则（来自专业人物海报范式）
1. **肖像为锚**：面部放在画面黄金区（约上 1/3 与中线交汇附近），大头构图，保证辨识与情绪传达。
2. **前后空间**：文字先画在底层，再把人物图（带透明背景抠像）合成到上层遮挡部分文字——人物在前、文字在后，形成空间纵深。
3. **字号强对比**：超大粗体主标题（占画面大量面积，第二视觉焦点）+ 小号辅助文案 + 最小号边角标注（如身份/日期）。一眼分清阅读顺序。
4. **3 色以内**：低饱和浅灰/纯色背景衬托人像；单一高饱和强调色（橙/红/品牌色）只用于主标题与装饰图形；黑白/深灰作基础文字色。

### 配色
| 风格 | 底色 | 强调色 | 文字 |
|------|------|--------|------|
| 力量感 | `#EDEAE4` 浅灰 | `#E63946` 正红 | `#1A1A1A` |
| 暗调高级 | `#14161A` | `#F5A623` 橙 | `#F5F5F5` |
| 品牌冷调 | `#0F1E3D` | `#3A6FF7` 蓝 | `#FFFFFF` |

### 文案公式
- 主标题：`<人设/主张>` → "把复杂的事 讲到人懂"
- 辅助：`<身份/领域>` → "十年内容操盘 · 自媒体导师"
- 边角标注：`<日期/场次/编号>` → "2026 秋季专场"

## 六、创意双关海报（情绪/态度向）

**气质**：以小见大、脑洞、共情。社媒传播、品牌态度、节点借势用。
**主视觉**：一个常见小物（水果/蔬菜/日用品/中药等）作主体，物品属性**双关**生活哲理——温暖或犀利均可。
**文案重心**：物品特性 → 人生/情绪隐喻（一句话点破）。

### 工作法则
1. **小物作主体**：选与主题强相关、辨识度高的日常物品，放大占主视觉。
2. **属性双关**：从物品的物理/文化属性出发做谐音或隐喻（如"软"的双关、"熟"的双关），不硬拗。
3. **情绪落点**：每句都要落到人——温暖治愈或锐利吐槽二选一，风格统一不摇摆。
4. **社会议题可借物说话**：用物品承载关爱/环保/反网暴等主题，比直给更克制有力。

### 文案公式
- 主标题：`<物品双关 + 态度>` → "别让软的 被随便捏"（示例结构，落地需据产品重想）
- 副标题：`<情绪/价值>` → "温柔也要有边界"
- 利益点：通常省略，保持态度纯净。

## 七、比例速查

| ratio 参数 | 尺寸(px) | 用途 |
|-----------|----------|------|
| `vertical` | 750×1000 | 电商主图、详情页首图 |
| `horizontal` | 1920×1080 | 网页 banner、PC 横幅 |
| `square` | 1080×1080 | 公众号封面、Instagram |
| `story` | 1080×1920 | 抖音/视频号封面、竖屏 |
| `wechat` | 1242×2208 | 朋友圈长图 |
| `custom:WxH` | 自定义 | 任意特殊尺寸 |

同一套文案+产品，循环 ratio 即可一键出全平台尺寸。
