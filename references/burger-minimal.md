# 极简商业美食海报（高端快餐/连锁品牌）

> `scripts/compose_burger.py` —— 给「生图产出的分层解构美食底图」叠极简文字层。
> 与 `compose_guochao_food.py` 的分工：

| 脚本 | 风格 | 装饰量 | 适用 |
|---|---|---|---|
| `compose_guochao_food.py` | 国潮小吃 | 满装饰（木牌/印章/弧框/书法） | 街边小吃铺、节庆物料 |
| **`compose_burger.py`** | **高端快餐** | **极简（只有标题+品牌）** | **连锁品牌广告、加盟物料** |

---

## 一、标准流程

```bash
# 1. 生图（混元）—— 提示词强调「full-bleed 满版」「上下预留干净区域」
# 2. 去水印 —— buddy-image-processing erase
# 3. 叠文字层 + 比例适配 + 导出
python scripts/compose_burger.py \
  --bg base.png --out final.png \
  --title "BEEF BURGER" \
  --tagline "SMOKED · GRILLED · STACKED" \
  --brand "ZHAPU CREATIVE" \
  --ratio 0.75 --save-size 1086x1448
```

## 二、分层解构底图的生图提示词模板

```
【主体】一个高级牛肉汉堡，垂直悬浮在画面正中央，是唯一主体。
        自上而下：芝麻面包 / 生菜 / 番茄 / 芝士 / 牛肉饼 / 洋葱 / 酱汁 / 底部面包
【分层解构】八层食材在垂直方向整齐悬浮排列，层与层之间留有均匀空隙，
        形成有节奏的高级分层感。上下两片面包轻微向上分离微微上扬，
        芝士片有轻微拉丝垂坠，酱料形成少量有光泽的悬浮液滴与拖尾。
        动态克制利落不杂乱。
【背景】深炭灰色哑光影棚背景，柔和渐变，顶部主光加两侧轮廓光。
【色调】暖棕色与金黄色调为主，高级商业质感。
画面上下预留干净区域供后期添加文字。
无人物，无手，无餐具，无水印，无文字。
```

**关键**：
- 「层与层之间留有均匀空隙」—— 否则模型会把食材粘成一坨，失去解构感
- 「动态克制利落不杂乱」—— 抑制模型把食材炸得到处都是
- 「上下预留干净区域」—— 不写这句，标题会压在主体上

## 三、比例适配：扩边而非拉伸（重要）

生图给的底图比例常与目标不符（实测：底图 2:3 = 0.667，目标 3:4 = 0.75）。

| 做法 | 结果 |
|---|---|
| 直接 `resize` | ❌ 汉堡被压扁变形 |
| 居中裁切 | ❌ 切掉上下留白与分层结构 |
| **扩边适配** | ✅ 主体不变形，留白保留 |

脚本的 `--ratio` 用「取边缘模糊条填充新区域」的方式扩边，保持 full-bleed 无边框：

```python
# 太窄（cur < target）→ 左右加宽
strip = im.crop((0, 0, W*0.06, H)).resize((pad, H)).filter(GaussianBlur(pad*0.12))
canvas.paste(strip, (0, 0)); canvas.paste(strip, (newW-pad, 0))
canvas.paste(im, (pad, 0))
```

`--save-size` 在比例对齐后等比缩放到目标像素（如 1086×1448）。

## 四、极简高级的文字规范

**核心原则：文字越少越高级。** 只有三层，且层层有分工：

| 层 | 内容 | 位置 | 手法 |
|---|---|---|---|
| 主标题 | BEEF BURGER | 顶部留白内（~0.035H） | **宽字距**（0.16em）+ 投影 + 1px 细描边 |
| 副标语 | SMOKED · GRILLED · STACKED | 标题下方 | 小字号、无描边、低透明度 |
| 品牌名 | ZHAPU CREATIVE | 底部居中（~0.895H） | 宽字距（0.30em）+ 描金细分割线 |

### 三个必做项

1. **字距加宽**：高级感靠 `letter-spacing`，不是靠描边堆砌。标题 0.16em、品牌名 0.30em。
2. **投影必备**：深色背景上白字必须有投影（`blur=18-22, alpha=185-190`），否则糊进背景。
3. **底部压暗**：底图底部常有桌面高光，叠一层渐变压暗既垫出文字对比、又遮掉干扰（`0.80H` 起渐变到 170 透明度）。

### 配色

```python
WHITE  = "#F5F1E8"   # 暖白（不用纯白，纯白在深底上刺眼）
GOLD   = "#C9A227"   # 描金（分割线）
SHADOW = "#0A0806"   # 投影（近黑带暖调）
```

## 五、常见错误对照

| 症状 | 病因 | 修法 |
|---|---|---|
| 标题被主体压住 | 标题 y 用 0.085H，落在主体上 | 先裁顶图确认留白范围（本例主体从 0.22H 起），标题放 0.035H |
| 白字糊进背景 | 无投影 | 加投影层（blur 18-22） |
| 白字有「发光感」不够贵 | 只用投影 | 补 1px 深色细描边 |
| 品牌名看不清 | 底图底部有桌面高光 | 底部渐变压暗 + 品牌名提亮 |
| 主体变形 | 直接 resize 到目标比例 | `--ratio` 走扩边适配 |
| 右下角有「AI生成」 | 忘了去水印 | 生图后必须跑 `erase` |

## 六、参数速查

```bash
--bg          底图路径（生图 + 去水印后）
--out         输出路径
--title       主标题（宽字距大字）
--tagline     副标语（可选，小字）
--brand       品牌名（底部居中）
--title-size  主标题字号（默认 76，基准画布高 1536）
--brand-size  品牌名字号（默认 38）
--tag-size    副标语字号（默认 22）
--ratio       目标宽高比（0.75 = 3:4），给了就扩边适配
--save-size   导出尺寸，如 1086x1448
```

字体：`Montserrat.ttf`（标题/品牌名，拉丁首选）、`NotoSansSC-*`（中文）。

## 七、技术备忘

**`ImageDraw` 对象没有 `alpha_composite`** —— 它只是绘图上下文，合成必须走画布 `Image` 对象：
```python
# ❌ 错误
d.im.alpha_composite(layer)
# ✅ 正确
im.alpha_composite(layer)   # im 是 Image 对象
```
这个坑在 `compose_guochao_food.py` 里也踩过一次，两个脚本都注意。
